# Notible — pakiet dla autorów pluginów

Wersja aplikacji: 0.48.2. API: 1.2.

- `START.md` — zacznij tutaj. Działający plugin w pięć minut.
- `REFERENCE.md` — pełna dokumentacja: każdy typ, metoda i slot.
- `notible-plugin-api.d.ts` — typy do podpowiadania w edytorze.
- `examples/pomodoro/` — kompletny, działający plugin.
- `examples/workbench/` — sprawdzian API: wszystkie sloty, nakładki,
indeks treści, własny arkusz stylów i panel ustawień.

Aby uruchomić przykład: Ustawienia → Plugin host → Add plugin folder,
wskazując `examples/pomodoro`.

Ten pakiet został zapisany przez aplikację, więc odpowiada dokładnie
tej wersji, którą masz zainstalowaną.
