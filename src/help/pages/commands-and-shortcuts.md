## The + menu

| Entry | Creates |
|---|---|
| New note | A note |
| Workspace | A workspace — a dashboard over several projects |
| Folder | A place to keep things together |
| Whiteboard | A canvas |
| Project | A project with task tabs |
| Task, Issue | A work item |

Plugins you turn on can add entries, such as **Manuscript** from Typewriter. The same entries are under **New inside…** in a row's right-click menu, to create something directly inside that folder, project or workspace.

## The / menu

Inside a note, `/` inserts blocks — see [Writing notes](help:writing-notes#blocks-from-the-menu). It also lists **Create project**, **Create task**, **Create issue** and **Create whiteboard**, which create a new item without leaving the keyboard.

## Keyboard shortcuts

| Keys | Does |
|---|---|
| `Ctrl+N` | New note |
| `Ctrl+K` or `Alt+Space` | Search |
| `F1` | Help |
| `Ctrl+,` | Settings |
| `Ctrl+Z` / `Ctrl+Y` | Undo / redo |
| `Ctrl+Alt+F` | Add a footnote |
| `[[` | Link to another note |
| `Ctrl+click` | Open a link |
| `Alt+←` | Back to the previous note |
| `/` | Insert a block |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | Everything bigger / smaller / back to normal |

Plugins can add their own shortcuts. **Settings → Hotkeys** lists them, and you can change a plugin's shortcut there; Notible's own shortcuts are fixed.
