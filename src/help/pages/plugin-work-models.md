Adds the work items themselves: **tasks**, **issues** and **projects**, and the links between them. It puts Project, Task and Issue into the **+** menu, and "Create project / task / issue" into the `/` menu.

Most other work plugins — Views, Planning, Automations — build on these, so this is the first one to have on if you want more than plain notes. See [Kinds of items](help:kinds-of-items).

**On by default.**

[Open Settings → Plugins](settings:plugins)
