Adds an **Automations** tab to projects: rules of the form "when this happens, do that". A trigger — an item is created, a property changes, a date is reached, or a schedule — runs actions such as setting a field or sending a notification.

To start, open a project's **Automations** tab and create a rule. Each rule reads as a sentence, can be previewed and run by hand, and every run is written to an execution log. Rules run on your computer only; nothing is sent anywhere.

**Off by default.** Needs [Tasks, Issues and Projects](help:plugin-work-models).

[Open Settings → Plugins](settings:plugins)
