Open Settings at the bottom of the sidebar, or press `Ctrl+,`. Search also finds individual settings by name.

## Appearance

Light (Daylight), dark (Midnight) or **Follow system**, which matches what Windows is set to. **Interface size** makes everything bigger or smaller on this computer (also `Ctrl+=`, `Ctrl+-` and `Ctrl+0`). **Notification sound** plays a soft sound when a reminder or a plugin notification shows inside Notible; it is off (None) until you pick one, and Windows notifications keep their own sound. Density: **Compact** fits more rows on screen in the sidebar, the editor and Settings. The interface language is chosen under Languages.

## Languages

Language packs for the interface. Anything not yet translated shows in English. Spell checking in notes follows the interface language; after you switch, it changes the next time Notible starts.

## Editor

Writing preferences and what the note footer shows.

## Files and links

What plugins may read (pasted images and your calendars), how a note prints to PDF, and the folders you have linked.

## Hotkeys

The keyboard shortcuts. A plugin's shortcut can be changed by recording a new key; Notible's own shortcuts are listed for reference and cannot be changed. Shortcuts for writing (undo, footnotes, links, Tab) are in [Writing notes](help:writing-notes).

## Plugins

Turn built-in plugins on and off, install from the market, and change each plugin's settings. See [About plugins](help:plugins).

## Recovery

Backups and the trash. See [Move, export and delete](help:move-export-delete#delete-and-restore).

## Updates and About

Check for and install updates, and see which version you are running and what changed in it. Plugin API and developer details are under **Technical details** in About.
