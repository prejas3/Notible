Adds the **Backlinks** list at the bottom of each note — every note that links to it — and the search support used across the app. Settings → Editor → **Backlinks and document stats** shows or hides the list. See [Finding things](help:finding-things).

**On by default.**

[Open Settings → Plugins](settings:plugins)
