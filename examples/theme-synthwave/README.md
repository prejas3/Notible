# Synthwave

A Notible theme: neon sunset over a wireframe valley, frosted-glass sidebar, pink accent.

Install: Settings, Plugins, Themes, Install from GitHub, then `prejas3/notible-theme-synthwave`.
Needs Notible 0.87.2 or newer. Turn it off any time with Ctrl+Alt+Shift+T or by choosing
"None (system theme)".

Built from the documented hooks only (`--notible-*` tokens and `data-notible-*` selectors);
see `THEME_PACKS.md` in the Developer pack. The background is a 1920 px JPEG.
